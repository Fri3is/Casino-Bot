# 🎰 Telegram Casino Bot

Полнофункциональный казино бот для Telegram с играми, платежной системой CryptoPay и административной панелью.

## 🎮 Возможности

### Игры Telegram
- **🎲 Кубик** - ставки на числа, четность, суммы двух кубиков
- **⚽ Футбол** - гол, промах, точные удары
- **🏀 Баскетбол** - попадания, отскоки, чистые броски
- **🎯 Дартс** - сектора, центр, игра "лучше"
- **🎳 Боулинг** - страйк, количество кеглей, игра "лучше"
- **🎰 Слоты** - джекпоты, мини-джекпоты, точные значения

### 💰 Финансовая система
- Пополнение через CryptoPay (USDT)
- Автоматические выплаты
- Настраиваемая комиссия (5-15%)
- Детальная статистика

### 👑 Административная панель
- Управление коэффициентами игр
- Настройка комиссии
- Статистика казино
- Управление резервом
- Добавление администраторов

## 🚀 Установка и запуск

### Требования
- Python 3.8+
- Токен Telegram бота
- Токен CryptoPay API

### 1. Клонирование репозитория
```bash
git clone <your-repo-url>
cd casino-bot
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка окружения
Скопируйте файл `.env` и настройте токены:

```env
BOT_TOKEN=your_telegram_bot_token
CRYPTOPAY_TOKEN=your_cryptopay_token
ADMIN_USERNAMES=oxegeo,yonalpy
DATABASE_PATH=casino_bot.db
```

### 4. Получение токенов

#### Telegram Bot Token
1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Создайте нового бота командой `/newbot`
3. Следуйте инструкциям и получите токен

#### CryptoPay Token
1. Откройте [@CryptoBot](https://t.me/CryptoBot)
2. Создайте приложение: `/newapp`
3. Получите API токен

### 5. Запуск бота
```bash
python main.py
```

## 📊 Типы ставок

### 🎲 Кубик
- Четное/нечетное число
- Больше/меньше определенного числа
- Конкретное число (1-6)
- Сумма двух кубиков (больше/меньше/равно 7)
- Произведение двух кубиков (диапазоны)

### ⚽ Футбол
- Гол/промах
- Попадание в правый верхний угол

### 🏀 Баскетбол
- Попадание/промах
- Чистый гол
- Отскок от кольца
- Застревание мяча

### 🎯 Дартс
- Белый/красный сектор
- Попадание в центр
- Отскок дротика
- Игра "лучше" (чем ближе к центру, тем выше выигрыш)

### 🎳 Боулинг
- Страйк
- Ни одной кегли не сбито
- Игра "лучше" (чем больше кеглей, тем выше выигрыш)

### 🎰 Слоты
- Джекпот (три одинаковых символа)
- Мини-джекпот (два одинаковых рядом)
- Угадывание точного значения
