# 🚀 FreelanceBot - Мощный фриланс-бот для Telegram

**ТАКОГО ЕЩЕ НИКТО НЕ ДЕЛАЛ! ЭТО ХАЙП!** 🔥

- ⭐ Система рейтингов и отзывов
- 💬 Встроенный чат
- 💳 Безопасные сделки
- 📊 Подробная статистика

### 💼 Для исполнителей:

- 💰 Создание откликов с предложениями
- 📈 Система репутации
- 💼 Портфолио и навыки
- 📈 Отслеживание доходов

### 🏆 Особенности системы:
- 🤖 AI-powered поиск и рекомендации
- 🔒 Эскроу-система для безопасности
- 📱 Адаптивный интерфейс
- 🌍 Мультиязычность
- 📊 Продвинутая аналитика

## 🛠️ Технологии

- **Python 3.9+**
- **python-telegram-bot** - Telegram Bot API
- **SQLAlchemy** - ORM для работы с БД
- **SQLite/PostgreSQL** - База данных
- **Redis** - Кэширование
- **Async/Await** - Асинхронная обработка

## 📦 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd freelance-bot
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка окружения
Отредактируйте файл `.env`:
```env
BOT_TOKEN=your_bot_token_here
DATABASE_URL=sqlite:///freelance_bot.db
REDIS_URL=redis://localhost:6379
ADMIN_IDS=your_telegram_id
```

### 4. Запуск бота
```bash
python bot.py
```

## 🎮 Использование

### Первый запуск
1. Отправьте `/start` боту
2. Выберите тип аккаунта:
   - 🛒 **Заказчик** - для размещения заказов
   - 💼 **Исполнитель** - для выполнения заказов  
   - 🎭 **Оба** - универсальный аккаунт

### Основные команды
- `/start` - Запуск и регистрация
- `/help` - Помощь по использованию
- `/profile` - Мой профиль
- `/orders` - Просмотр заказов
- `/create` - Создать заказ
- `/stats` - Статистика
